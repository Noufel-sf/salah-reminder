## 🇸🇦 باللغة العربية

### 📖 نبذة عن المشروع
**نُور** هو تطبيق مكتبي إسلامي حديث ومتكامل لنظام تشغيل **Windows**، صُمم خصيصاً ليكون رفيق المسلم الدائم على حاسوبه. يجمع التطبيق بين **الدقة الفلكية المعتمدة بنسبة 100% بدون إنترنت**، و**التصميم الروحاني الفاخر ذو الزوايا المستقيمة الكلاسيكية (`rounded-none`)**، مع تجربة مستخدم سلسة وهادئة تعمل في الخلفية دون أي تشتيت أثناء العمل أو التصفح.

---

### ✨ أبرز الميزات

#### 1. 🕌 مواقيت الصلاة والأذان المعتمد
- **دقة فلكية تامة**: احتساب أوقات الصلوات محلياً بدون الحاجة لأي اتصال بالإنترنت عبر مكتبة `adhan` الموثوقة.
- **اعتماد رسمي جزائري**: زاوية الفجر 18°، زاوية العشاء 17°، واحتياط الغروب +3 دقائق، متطابق رسمياً مع رزنامة وزارة الشؤون الدينية والأوقاف الجزائرية لولاية قسنطينة وسائر الولايات.
- **11 طريقة حساب دولية**: دعم شامل لكافة الطرق المعتمدة (رابطة العالم الإسلامي، أم القرى، الهيئة المصرية، جامعة كراتشي، دبي، قطر، الكويت...).
- **الضبط اليدوي بالدقائق**: إمكانية تقديم أو تأخير أي صلاة بدقة لضبط وقت الأذان مع مسجد حيك.

#### 2. 🔊 أصوات الأذان الحقيقية المدمجة
- باقة من أجمل الأصوات المسجلة بجودة نقية دون الحاجة لتحميل:
  - الأذان الجزائري الأصيل.
  - أذان الحرم المكي الشريف.
  - أذان الحرم النبوي المدني.
  - أذان الفجر الخاص بصيغة *«الصلاة خير من النوم»*.
  - نغمات رنين هادئة وصامتة مع شريط تحكم دقيق بمستوى الصوت.

#### 3. 🪟 شريط الويدجت العائم لسطح المكتب (Always-on-Top Widget)
- شريط مصغر شفاف ودائم الظهور فوق جميع النوافذ وبرامج العمل.
- يعرض اسم الصلاة القادمة والوقت المتبقي بالعد التنازلي الحي.
- زر تسبيح سريع (+1) وزر فتح التطبيق الرئيسي أو إغلاق الويدجت.
- يعمل كنافذة سطح مكتب مستقلة خفيفة أو كشريط طافٍ داخل التطبيق.

#### 4. 📿 المسبحة الإلكترونية ومحطات التحفيز القرآني (Dhikr Milestones)
- عداد تسبيح تفاعلي يدعم (سبحان الله، الحمد لله، الله أكبر، أستغفر الله، لا إله إلا الله، لا حول ولا قوة إلا بالله).
- **بطاقة التحفيز الإيماني**: عند إتمام الهدف (مثل 33، 99، 100، 300، 1000 ذكر) تنبثق بطاقة فخمة تحتوي على آية قرآنية كريمة وحديث نبوي شريف ونفحة تأملية مع رنين رخيم.
- حفظ تلقائي لكافة الإحصائيات (اليومية والكلية) بشكل دائم.

#### 5. 📖 المصحف الشريف ووضع الجمعة المباركة (Jumu'ah Mode)
- قارئ سورة الكهف الكامل والمدمج داخل التطبيق بخط المصحف العثماني الجميل.
- تنبيه صباح كل جمعة لقراءة سورة الكهف لنيل النور ما بين الجمعتين.
- تنبيه ساعة الاستجابة قبل غروب شمس الجمعة بساعة للتفرغ للدعاء.
- عداد الصلاة على النبي ﷺ مع أهداف تفاعلية (100، 300، 500، 1000 صلاة).

#### 6. 🌙 تنبيهات صيام النوافل والأيام البيض
- تذكير بصيام يومي الإثنين والخميس مساء الأحد والأربعاء.
- تذكير تلقائي بصيام الأيام البيض (13، 14، 15 من كل شهر هجري).
- متابعة نية الصيام اليومية بضغطة زر واحدة.

#### 7. 🔔 التذكير الدوري العشوائي بالأذكار
- إرسال إشعارات ويندوز مصحوبة بصوت نقرة المسبحة وبطاقة طافية بأذكار مأثورة وفضائلها على فترات قابلة للتخصيص (عشوائي بين 15-35 دقيقة، أو كل 15، 30، 45، 60 دقيقة).

#### 8. 💻 تكامل ويندوز وصينية النظام (System Tray)
- تصغير هادئ إلى جوار الساعة في ويندوز (`System Tray`).
- تلميح الفأرة (`Tooltip`) الحي يوضح الصلاة القادمة والوقت المتبقي لحظة بلحظة.
- قائمة زر أيمن غنية للتسبيح السريع، كتم الصوت، أو فتح الويدجت.
- التشغيل التلقائي الهادئ مع إقلاع النظام عبر وسيط `--hidden`.
- اختصار عالمي من أي نافذة: `Ctrl + Shift + P` لإظهار أو إخفاء التطبيق فوراً.
- تسبيح سريع عبر مفتاح `Space` في أي مكان في التطبيق.

#### 9. 🎨 الوضع النهاري والليلي الفاخر (Theme & Aesthetics)
- دعم كامل ومتناسق لكل من الوضع النهاري الفاتح والوضع الليلي العميق بدرجات `dark:bg-[#0e1914]` الفاخرة مع تبديل بصري فوري.
- الالتزام التام بفلسفة الزوايا المستقيمة الخالصة (`rounded-none`).

#### 10. 🌿 جولة الترحيب والإعداد الأولي (Onboarding Tour)
- معالج إعداد سريع مكوّن من 3 خطوات ينبثق تلقائياً عند أول تشغيل لاختيار المدينة، المؤذن المفضل، وتفضيلات سطح المكتب.

## 🇬🇧 In English

### 📖 About the Project
**Noor** (Arabic for *Light*) is a premium, modern, and comprehensive desktop companion for Windows designed to elevate your daily Islamic worship. Built with performance, privacy, and spiritual elegance in mind, it operates **100% offline**, features **certified calculation models**, and integrates seamlessly into the Windows desktop environment without interruptions.

---

### 🌟 Key Features

- **⏱️ 100% Offline Accurate Prayer Times**: Powered by astronomical spherical calculations via the proven `adhan` engine.
- **🇩🇿 Official Algerian & International Presets**: Pre-configured with the official Algerian Ministry of Religious Affairs standard (18° Fajr, 17° Isha, +3 min Maghrib safety margin), plus 11 global authorities (MWL, Umm Al-Qura, Egyptian, Karachi, Dubai, etc.).
- **🔊 Bundled Studio Adhan Audios**: High-fidelity local adhan audios including Algerian, Makkah Haram, Madinah Haram, and Fajr prayer call.
- **🪟 Always-on-Top Mini Desktop Widget**: A transparent, floating HUD displaying the upcoming prayer, live countdown ticker, and a one-click quick Tasbih counter.
- **📿 Digital Tasbih with Spiritual Milestones**: An interactive Misbaha that unlocks inspiring Quranic verses and authentic Hadith celebrations upon reaching goals (33, 99, 100, 300, 1000).
- **🕌 Blessed Friday Mode (Jumu'ah)**: Full in-app Surah Al-Kahf reader, Jumu'ah morning notification, and Hour of Response (*Sa'at Al-Ijabah*) reminder before sunset.
- **🌙 Sunnah Fasting Notifications**: Smart alerts for Monday/Thursday fasting and the lunar White Days (13th, 14th, 15th of Hijri months).
- **🔔 Periodic & Ambient Dhikr Reminders**: Non-intrusive Windows notifications delivering authentic Athkar and virtues on customizable intervals.
- **💻 Native Windows Desktop Integration**:
  - Minimizes gracefully to the System Tray.
  - Hover tooltip displays live upcoming prayer and remaining duration.
  - Single Instance Lock (prevents duplicate processes).
  - Silent auto-start at Windows login with the `--hidden` flag.
  - Global Hotkey: `Ctrl + Shift + P` to toggle visibility anywhere in Windows.
  - Spacebar quick Tasbih tap with soft organic prayer bead sound.
- **🎨 Premium Dark & Light Aesthetics**: Bespoke palette featuring deep forest green, obsidian emerald (`#0e1914`), sharp straight corners (`rounded-none`), and instant live theme preview.
- **🌿 First-Launch Onboarding Wizard**: A welcoming 3-step setup guide for new users to personalize their city, muezzin audio, and startup preferences.

## 🛠️ البنية التقنية | Tech Stack

| **Calculation Engine** | [Adhan.js](https://github.com/batoulapps/adhan-js) (Batoul Apps) |
| **Installer Packaging** | [electron-builder](https://www.electron.build/) (Windows NSIS Setup Executable) |

## 🚀 التثبيت والتشغيل | Getting Started

### المتطلبات الأساسية | Prerequisites
- **Node.js**: v18.0.0 أو أحدث (v20+ موصى به).
- **npm** أو **pnpm** أو **yarn**.

---

### 1. استنساخ المستودع | Clone Repository
```bash
git clone https://github.com/Noufel-sf/salah-reminder.git
cd salah-reminder
```

### 2. تثبيت الحزم | Install Dependencies
```bash
npm install
```

### 3. تشغيل وضع التطوير | Run in Development
```bash
npm run dev
```
> سيتم تشغيل خادم التطوير السريع `Vite` وتفتح نافذة تطبيق `Electron` تلقائياً.

---

### 4. التحقق واختبار البناء | Verify Build
```bash
npm run build
```
> يتحقق من سلامة كافة أنواع الـ TypeScript ويجمع حزم الإنتاج داخل مجلدي `dist` و `dist-electron`.

---

### 5. بناء ملف التثبيت الرسمي لويندوز | Build Windows Installer (.exe)
```bash
npm run package
```
> سيقوم `electron-builder` بتوليد ملف التثبيت التنفيذي المكتمل:
> **`release/نور Setup 1.0.0.exe`** (مع اختصارات سطح المكتب وقائمة إبدأ).

## ⌨️ اختصارات لوحة المفاتيح | Keyboard Shortcuts

| الاختصار / Shortcut | الوظيفة بالعربية | English Function |
|---|---|---|
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | إظهار أو إخفاء التطبيق فوراً من أي مكان في ويندوز | Global Hotkey: Toggle app window visibility from anywhere |
| <kbd>Space</kbd> | التسبيح السريع (+1) في أي شاشة مع صوت المسبحة الرخيم | Quick Tasbih (+1) anywhere in the app with organic bead sound |
| <kbd>Escape</kbd> | إغلاق النوافذ المنبثقة وشاشات الترحيب وقارئ الكهف | Dismiss modals, onboarding tour, or Surah reader |
